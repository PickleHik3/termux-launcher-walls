# Recompose a wallpaper for Termux Launcher

Adapt the attached image for Termux Launcher using the minimum changes necessary. Preserve the original artwork’s appearance while making deliberate positional changes for terminal readability.

## Canvas

Target aspect ratio = **(1.5 × phone portrait screen width) : phone portrait screen height**. If screen dimensions are not provided, use **27:40**. Extend the scene naturally to fit; do not stretch it.

## Composition

The launcher displays a screen-sized portion of this wider image and pans horizontally between pages. The terminal normally shows the central two-thirds of the full canvas.

Keep that central region relatively calm so terminal text remains readable. Use existing negative space first. Move distracting focal subjects and high-contrast details toward the periphery only as much as necessary. Keep important subjects recognizable and at least partly visible within the central two-thirds where practical.

Make these changes by repositioning existing elements and naturally repairing or extending their surroundings. Accept some original detail rather than forcing a large empty area. Do not merely redraw the original composition if it leaves the same distractions behind the terminal.

## Preservation

Preserve the original subjects, artistic style, brushwork, textures, palette, lighting, atmosphere, and relative scale wherever possible. Preserve how elements look; their positions may change when needed for readability.

Keep unchanged regions intact wherever possible. Do not embellish the scene, add new subjects or decorative details, intensify lighting, increase visual complexity, or redesign the scenery. Newly exposed or extended areas should quietly continue nearby scenery.

## Color and detail

Preserve broad, natural color variation throughout the image so the launcher’s compact and expanded status bar, dock, and keyboard can sample attractive colors for their glass effects. Avoid concentrating sharp highlights or busy patterns behind the central reading area.

Keep the top and bottom relatively calm without imposing fixed bands or boundaries. Do not globally blur, darken, sharpen, or recolor the artwork.

## No interface artwork

Never draw launcher surfaces, terminal windows, panels, outlines, borders, rounded rectangles, frosted glass, interface shadows, or surface-shaped clearings. Negative space must look natural within the scene. All glass and blending effects are handled by Termux Launcher.

## Output

Return one standalone wallpaper image at the target aspect ratio, at the highest practical resolution. No mockup, labels, comparison grid, or explanatory text inside the image.

Prioritize minimal changes to appearance while making the positional changes needed for terminal readability.
